# 2.15.13 — build 1

The program's volume now follows the phases you see, a set you remove
stays removed for one week only, and history shows only what you did.

## Sets follow the phase table
- **Establish** one set under the program. **Accumulation** the program,
  then one over from its second week. **Intensification and Peak** back
  to the program while the loads climb. **Deload** 2 sets. An 8-week
  meso with 4-set anchors runs 3 4 5 4 4 4 4 4 2.
- The old rule split the weeks into thirds and put the extra set in the
  Peak weeks, with Accumulation one set under the program. The opposite
  of what the overview promised.

## A set you add or remove lasts the week
- Remove a set and next week opens on the program's count again. Same
  for an added set. The old delta carry re-applied a one-time trim to
  every later week until you added the set back by hand.
- Set-count choices are wiped when a meso ends. They used to survive,
  and the next meso read them as its own.

## History is finished weeks and confirmed sets
- The lift history sheet lists the weeks before the one you're in, with
  confirmed sets only. No "Today" row.
- Opening a day builds suggestions for every exercise, and the first
  save of any set stored them alongside real work. The history sheet,
  the LAST WK chip, the e1RM and PR charts, Lifts by Muscle, Current
  Weights, muscle volume, PR and stall detection, and the left-open set
  count all showed a suggestion as a lift. None of them do now.

## Week 1 starts where you left off
- A new meso's week 1 prescribes the top working set of your last hard
  week, reps at the bottom of the range, as an unconfirmed suggestion.
  Lifts with no previous loaded reference open blank as before.

## Copy matches code
- Learn, the tour, the phase-table notes, the deload rows, the card's
  Target cell, About and the meso-complete sheet all describe what the
  app actually does: the double-progression gate, the real increments,
  the week-1 deload taper, and RIR as a target you hold yourself to.
  "Stall twice? The Foundry deloads you" is gone. Nothing did that.
