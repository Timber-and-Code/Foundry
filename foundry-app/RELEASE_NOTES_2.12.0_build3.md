# The Foundry 2.12.0 (build 3)

Three fixes since build 2. Cut 2026-07-28.

## What to Test

**No more orange peeking behind the banner (Home)**
- On Home, nothing should be visibly clipped behind THE FOUNDRY banner or the session bar — the amber coach-tip card (and any first card) must sit fully below the header, top edge intact.

**Readiness strip fully visible (workout)**
- Start a workout. The "HOW ARE YOU FEELING?" title and the skip link must be fully visible above the OFF / OK / STRONG buttons — nothing cut off under the session bar.

**Forgot password from inside the app**
- Signed out, tap Log in → Forgot password? with your email filled in. The email link must open Safari on the NEW PASSWORD form (two fields + Update password), not the sign-in screen.
- Reminder: reset links are one-time and expire in ~1 hour — always use the newest email.

Build 2's session-bar checks still apply: ← Back, SESSION timer, STOP, and the REST chip visible in the bar under the banner throughout a workout.
